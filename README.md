# 运动时长累计 · Motion Ledger

> 丸子的无限进步 · 小红书 / 视频号同名账号

一个**零依赖的单文件网页**，用来记录「一生累计运动了多少小时」。
深空蓝青科技风，手机浏览器也能打开，可加到主屏幕当 App 用。

## 它能做什么

- **累计大盘**：一生总小时数 + 年度目标环形进度；本周 / 本月 / 今年 / 连续天数四个指标
- **今日课程**：按星期自动带出当天固定课，点「确认完成」计入；时长可临时改；没去点「跳过」
- **临时打卡**：滑板 / 游泳 / 爬山 / 徒步 / 其他，选项目 + 填时长 + 选日期
- **数据视图**：项目分布条形图、累计增长曲线、GitHub 风格年度热力图
- **记录流水**：逐条可删；支持 JSON 导出 / 导入

## 内置课表（可在源码 FIXED 里改）

| 时段 | 内容 |
|---|---|
| 周一 / 周三 晚 | 瑜伽 90 分钟 |
| 周二 / 周四 中午 | 拉丁 60 分钟 |
| 周二 / 周四 晚 | 羽毛球 90 分钟 |
| 周五 / 周日 晚 | 拉丁 90 分钟 |
| 周六 早上 | 瑜伽 90 分钟 |

每周 12.5 小时，一年约 650 小时。

## 使用

1. 下载 `运动时长累计.html`，双击打开（无需联网、无需安装）
2. 点右上角「设置」，先填一个**历史基数**（过去累计的小时数），再填年度目标
3. 之后每天点一下当天的「确认完成」，临时运动走下面的打卡区
4. 手机：用浏览器打开后「添加到主屏幕」

## 关于数据

数据只保存在**当前设备的浏览器 localStorage** 里，不上传任何服务器。
换设备或清缓存前，请在设置里**导出 JSON** 备份。

## 技术

单文件 HTML + 原生 JS，图表全部手写 SVG，无任何外部依赖（离线可用）。
